# 多列排序与游标分页（从 0 实现）

起始环境里只有本说明、`samples/**` 与 `.gitignore`：引擎、页面、测试都新写。Python 3.13、只用标准库；
页面是单文件 HTML，无构建无依赖；测试用 unittest。

## 一、范围

做：一个分页库（库 + 命令行入口 `pager.py`），按页序列文件给定的多列排序翻到任意深的一页——每页返回一批
记录和指向本页最后一行的游标，下一页拿游标来换；再把每次翻页的结果渲染成自包含页面 `paging.html`。

不做：过滤与检索、连接与聚合、跨进程续页（一次 `run` 跑完整串请求）、写数据文件（`samples/**` 只读）、
缓存与并发事务（变更只是"数据被改了"）、第三方依赖与构建步骤。

## 二、口径与公式

- **排序**：`sort` 是有序的列列表，每列 `{field, dir, nulls}`，`dir` 取 `asc|desc`，`nulls` 取
  `first|last`。从左到右逐列比：数字按数值，字符串按 Unicode 码位（Python 默认字符串序），相等就看下一列；
  全相等时按 `id` 升序打破，得到唯一全序 `(列1, 列2, …, id)`。
- **空值**：`nulls` 决定该列空值排最前还是最后，**与 `dir` 无关**；空值之间一律相等。
- **游标**：不透明字符串 `v1.<载荷>.<校验>`；`<载荷>` 是 base64url（去掉 `=`，字符集 `A-Za-z0-9-_`）编码
  的紧凑 UTF-8 JSON，`<校验>` = `sha256("cursor-v1|" + 载荷).hexdigest()[:16]`（小写十六进制）。
- **载荷必须带**：版本、本轮快照标识、排序口径指纹、本页最后一行的 `id` 与各排序列取值；指纹 = 把 `H` 行的
  `排序=` 值原样做 `sha256` 取前 16 位。载荷里不能只放行号或偏移量。
- **校验与拒收**：格式、校验位、JSON 结构、字段、指纹、快照标识任何一项不符都判 `CURSOR_INVALID`：该步不
  返回任何行、不写 `P` 行，也**不许**退回从第一页重来。
- **变更中的口径**：一轮从无游标的请求开始，到本页返回 0 条或条数少于页大小为止；轮开始时取快照，轮内所有页
  都读它，所以轮内的插入、删除、改值都不影响该轮：已返回的不再出现，没返回的不会因为被删掉而不见，插到前面
  的也不会挤进来。只有新的一轮才看得到最新数据。

## 三、状态机与数据结构

- 轮的状态：`未开始 → 进行中 → 结束`；游标只在进行中的这一轮里有效，轮结束后再用该轮游标一律拒收。
- 结构：按全序排好的索引 + 按游标键元组二分定位；索引一次 `run` 建一次，取第 k 页不许从第一行数起。记录
  至少含唯一 `id` 与各排序列；同一列的值类型必须一致（数字、字符串或空），混用即输入不可用。
- 每页从索引里取出的记录条数记作 `扫描`；**`扫描 ≤ 页大小 + 8`**，且与页序无关。

## 四、输入输出与文件格式

本节文件都是 UTF-8 无 BOM、LF 换行、末行有换行。

**4.1 数据 `samples/data/<名>.json`**：`{"name": …, "rows": [ … ]}`；每行必须有唯一整数 `id` 与各排序列，
值只能是数字、字符串或 `null`。

**4.2 页序列 `samples/pages/<名>.json`**：`{"name", "data", "limit", "sort", "steps"}`；`data` 指数据文件，
`limit` 是页大小。`steps` 每步是：新一轮 `{"op":"page","cursor":null}`（取新快照）；续页
`{"op":"page"}`（带上一页的游标，`"repeat":n` 连着来 n 次）；篡改
`{"op":"page","cursor":"tampered"}`（把上一页的游标改动末位）；字面
`{"op":"page","cursor":"literal:<原文>"}`；变更 `{"op":"mutate","insert":[行…],"delete":[id…]}`（改当前
数据；不得改写 `samples/**`）。

**4.3 结果文件与期望文件 `samples/expected/<同名>.txt`**，一行一条：

```
H|<序列名>|数据=<文件名>|页大小=<n>|排序=<字段:升降:空值,…>|轮数=<n>|扫描上限=<n+8>
M|<步>|插入=<id,…|->|删除=<id,…|->
P|<轮>|<轮内页序>|<游标来源>|<行数>|<位次|->|<id,…|->|扫描=…     ← 结果文件，期望文件写 |扫描<=<上限>
E|<轮>|<步>|<literal|tampered>|游标被拒
C|<轮>|页数=<n>|行数=<n>|唯一=<n>|重复=<n>|缺失=<n|->|结论=<不重不漏|未翻完|游标被拒|存在异常>
T|轮数=<n>|页数=<n>|行数=<n>|唯一=<n>|重复=<n>|缺失=<n>|结论=<不重不漏|存在异常>
```

`游标来源` = `start`（本轮第一页）或 `p<轮内页序>`；`位次` 是本轮内已返回条数的区间，空页写 `-`；`重复` =
轮内返回条数 − 不同 `id` 数；`缺失` = 轮结束时本轮快照里没返回的 `id` 数（没结束写 `-`）；每页都返回游标，
空页返回收到的那个；`结论` 只有每轮都翻到底且重复、缺失都是 0 才是 `不重不漏`。

**4.4 命令行**

```
python pager.py run <数据文件> <页序列文件> <结果文件>
python pager.py report <结果文件> <页面文件>
```

仓库根目录执行；`pager.py` 既是库也是入口，公开接口自定（写进模块 docstring）；诊断走 stderr；退出码 0 表示
跑完，1 表示输入不可用且不写输出文件（页大小越界、列值混型、`id` 重号）。

**4.5 页面**：`report` 只读结果文件，不读数据、不重算。单文件 HTML，样式内联，无脚本、无外部引用，跑两遍
逐字节相同；内嵌 `<pre id="trace">`，内容与结果文件（去掉末尾换行，按 `&`→`&amp;`、`<`→`&lt;`、
`>`→`&gt;` 转义）逐字节相同。页面上要有：① 摘要（`H`/`T` 行各项）；② 明细（按 `P` 行顺序给各字段，
`M` 行插原位，被拒的 `E` 行用颜色区分并写进图例）；③ 结论（末尾 `T` 行的核对结论）。

## 五、性能与验收口径

规模：04 号 2 万行、`页大小=2`、10001 页。

- 建序允许一次 `O(n log n)`；单页 `扫描 ≤ 页大小 + 8`，与页序无关，不许 offset 式从头扫。
- 时间：参考机（本机 CPython、单进程单线程、SSD）04 号 `run` ≤ 20 秒，其余样例与 `report` ≤ 5 秒。
- 对拍（逐条可核）：与 `samples/expected/<同名>.txt` 逐行比——`H`/`M`/`E`/`C`/`T` 行逐字节相同，`P` 行除
  末字段外逐字节相同，末字段 ≤ 期望的 `扫描<=n`。
- 确定性：同一条命令跑两遍逐字节相同，`report` 也一样；页面 4.5 三项齐全、内嵌 `trace` 与结果文件一致。
- 测试：`python -m unittest discover -s tests` 全绿，只用标准库、只读 `samples/`，测试自己写。

## 六、样例说明

`{data,pages,expected}` 三个目录下同名文件一一对应；括号里是页大小 / 轮数 / 页数 / 返回行数。

| 样例 | 行数 | 场景与关键结果 |
| --- | --- | --- |
| `01-plain` | 12 | 基础盘（5 / 1 / 3 / 12）：`ppm` 降序、`zone` 升序，末页只有 2 条 |
| `02-tie-dense` | 36 | 并列值密集（4 / 1 / 10 / 36）：`ppm` 只有 3 个取值、`zone` 大面积并列，次序全靠 `id` 打破；第 9 页满页，再要一页返回 0 条 |
| `03-nulls` | 16 | 空值（3 / 1 / 6 / 16）：数字列升序且空值排前，字符串列降序且空值排后 |
| `04-deep` | 20000 | 极深分页（2 / 1 / 10001 / 20000）：1 万页每页 2 条，末页之后再要一页；每页 `扫描≤10` |
| `05-churn` | 24 | 翻页中插入与删除（4 / 2 / 14 / 49）：第 3 步插入 3 行（含排在最前的）、删除 2 行（1 行已返回、1 行没返回），轮1 仍按旧视图翻完 24 行；轮2 才看到新的 25 行 |
| `06-guard` | 8 | 游标校验（3 / 4 / 5 / 14）：外部伪造、改动末位、截断的游标各一次，全部记 `CURSOR_INVALID` 且不返回任何行 |

`samples/notes.md` 是现场记录（背景不是规格），有冲突以本文件为准。
